## 2. 保留而未改的合同

- 初次/增量共用八站；系统阶段自动推进、人工门槛显式确认；冻结不自动启动分析。
- 首期一个 Git、一个目录或两者；目录至少一个文件、完整枚举/验证；空 Git 和空目录边界不变。
- §6–8 原有来源身份、SHA/manifest、Gap 接受、权限、安全、幂等发布、TTL=0、恢复、存储及备份规则保持原文。
- §11 的类型、F002 准入、完整 Gap 继承与文件 Delta 合同保持原文；不在此决定 F007 O03 的具体读取接口或会话关联 API。
- 来源版本、事实集、图谱与执行身份不合成一个通用版本；新来源不自动改旧答卷、旧分析或旧引用。
- 材料保存在来源系统；会话只保存其引用。F001 不接管会话、七问答卷、贡献、人工决定、影响计算或外部 AI 授权管理。
- 三张 2026-09-18 PNG 原样保留；214/212/2 示例关系不变，不把示例数值写成配额。F005、其他 Feature、英文历史稿、ADR、代码、部署及生命周期文件均不在本次修改范围。

## 4. 后续验证边界

正文新增的是要求：复用已有材料、会话接入与返回、冻结/关联失败分离、精确引用及权限变化、同状态双主题与统一缩放。文档/链接检查只证明内容和引用结构，不能证明这些功能已实现。

跨 Feature 的会话关联、持久化、权限及联合恢复需相应服务证据；F001 原有 B-01–B-13（包括十万文件和配套备份恢复）全部保留。F007 的未定 API、试点业务、执行证据更新和分析发布规则不因本次页面调整被提前裁决。
