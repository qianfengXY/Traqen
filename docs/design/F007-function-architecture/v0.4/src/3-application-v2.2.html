依赖与校验规则
读：消费者（Web · AI · CI）只读答卷投影／查询，不直读存储；默认读当前受控头，响应注明版本上下文；返回按当前调用者权限与外发策略过滤，缓存亦然。
写：工作会话统一入口、分路校验 —— 调查发现与解释候选→五档分流（只进分析态）；人工正式决定与正向登记→决定流程（追加式、服务端分配身份）；新增材料→F001 冻结准入；执行结果→证据摄取与版本绑定。
失效：真相更新（人工决定生效，或新分析经发布门禁获准、图谱头前移）→投影重算；新分析未获准时保留旧头并标「新分析尚未生效」；版本变化→受影响条目待复核；依赖的有效期到达→重新评估（历史答卷保留原评估时点）；均不自动推翻原结论。以上以依赖检查（CI 规则）守护；已知例外（如 D1b 备份归档直连数据库）在代码中显式标注。
