② Cloudflare → Node 源站：接线未证实；两段提案分别画清——

提案 A（推荐）：Cloudflare Tunnel。源站常驻 cloudflared 连接器；CF 边缘 ↔ 连接器为出向加密隧道；连接器 → Node 可配 HTTP；无需公网暴露源站与源站证书。代价：引入 cloudflared 外部依赖。

提案 B：Full(strict) 直连，两段协议分开画：Cloudflare —HTTPS→ 反代（Caddy 自动证书 / nginx；CF 官方要求源站 HTTPS + 有效证书）—HTTP→ Node（与已核实 Node 入口一致）；可叠加源站防火墙仅放行 CF 源站 IP。代价：证书管理与源站暴露；若反代 → Node 也走 HTTPS，须另列 Node TLS 端点新增设计。
