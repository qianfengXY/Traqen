面向无可信资产存量系统的企业可追溯质量平台 · 业务能力与价值产出视图
视角：业务与治理 · 不含任何技术实现细节 · 修订 v4 · 保留 v2 / v3 供对照
业务角色
R1产品 / 业务负责人
确认功能目标、业务规则与验收基线，对业务定义签字负责。
R2架构师与研发
登记来源材料、重建系统知识、评估变更影响并修复缺口。
R3测试与质量
圈定验证范围、留存真实执行证据、跟踪并处置质量缺口。
R4交付与运维
按版本查证完整证据链，支撑交付验收与运行期审计。

态势与证明
B01知识重建与资产化
从存量材料识别功能、流程与规则，保留来源、歧义与缺失。
B02业务定义与基线治理
确认功能目的、规则、范围与责任，留存版本与决策历史。
B03端到端关联与质量追溯
意图、设计、实现、配置、测试、部署类型化关联，断链可定位。
B04测试设计与质量验证
规则推导测试规格，连接真实执行与断言，产出可信结论。
B05变更影响与持续回归
版本间差异比较，影响按确定、可能、未知三级显式分级。
B06质量缺口与协同处置
缺失、陈旧、冲突、失败统一登记，补证、修复或风险接受留痕。
B07质量态势与交付证明
按功能、版本、部署汇合质量状态，导出证据与剩余风险。
价值产出
V1软件知识可继承
功能资产不依赖个人记忆，随人员更替持续可用、可交接。
V2质量可解释
每个质量结论都能追溯到证据、判定人与判定依据，绝不合成总分。
V3交付可查证
交付验收依据完整证据链与剩余风险清单，而非口头承诺。
治理贯穿
B16角色与权限
按角色划分操作边界，越权操作被拒绝并留痕。
B17禁止自我审阅
提出假设者与审阅决策者分离，结论须经独立确认。
B18人工审批
单人、双人、业务合规与紧急破窗四级审批模式。
B19证据审计
关键操作全量留痕，审计视角可回放完整决策链。
