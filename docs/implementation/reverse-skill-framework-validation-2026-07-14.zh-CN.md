# Reverse Skill 框架验证 — 2026-07-14

## 产品边界

该切片实现了可替换的 Reverse Skill 协议，而不允许 Skill 成为事实来源或业务权威。成功运行以 `WAITING_REVIEW` 结束；它无法创建规范的 Claim、Decision、一致性结果、批准的 TestSpec 或完整的 TraceChain。

内置 `specone-reference` 和 `gsd-reference` 适配器是用于执行通用协议的确定性 compatibility/reference 实现。它们并不声称已集成外部 Specone 或 GSD 产品、提示、模型或服务。两者都使用完全相同的受控 Fact 包，并且可以在不更改存储或合并合约的情况下删除或替换。

## 验证流程

```text
签署已安装的 Skill 清单
→ 追加 ALLOWED/OBSERVE/BLOCKED 注册事件
→ 选择准确的 Fact Bundles 和任务范围
→ 创建最小的不可变输入包
→ 执行项目、Snapshot 清单、来源 Snapshot 和政策
→ 使用 timeout/retry 边界执行摘要匹配的内置适配器
→ 拒绝敏感或未声明的输出
→ 单独保留原始输出
→ 用 Fact 证据使候选人正常化
→ 所有生产者来源的精确重复数据删除
→ 范围感知冲突分析
→ 追加运行事件、尝试、候选者、冲突和悬而未决的问题
→ WAITING_REVIEW
```

自动化测试在一次运行中验证两个适配器、显式对立约束冲突、不相交范围中的非冲突业务变体、精确重复保留、未知证据拒绝、任务范围转义拒绝、服务器端输入和原始输出上限、敏感或未声明的输出拒绝、超时重试、工件摘要不匹配、发布者签名失败、不完整的-Fact策略以及立即阻止先前允许的Skill 版本。

## 信任和不变性

- 清单 HMAC 证明绑定发布者、Skill ID/version、工件摘要、权限、兼容性和执行策略。
- 注册仅接受 ID、版本和摘要与签名清单完全匹配的编译适配器。
- 供应状态变化是新的不可变注册事件；即使挂钟时间戳发生冲突，单调的服务器事件顺序也会使最新事件成为执行策略投影。
- 每次运行都会固定一个精确的 Skill 版本。任务范围支持精确的工件、Fact 节点 IDs/types 和模块。拒绝未知范围的字段或引用，而不是默默地扩大分析；策略上下文、时间戳和最大输入大小由服务器控制。
- 输入 ID 和摘要涵盖不可变的 Fact 选择、Scope 和策略上下文，但排除观察时间戳，因此相同的受控内容仍然可重复识别。
- 输入包含结构化的 Facts 和关系，绝不是不受限制的文件系统、数据库、Shell、网络或秘密访问。
- 源内容标记为 `UNTRUSTED_SOURCE_CONTENT`；确定性适配器不会将源文本解释为控制指令。
- 每个候选 Feature、Claim 和 TestSpec 都从确切的输入包中引用节点 Fact 或关系 Fact。
- 原始 Skill 输出和标准化 `ReverseArtifactBundle` 存储在单独的数据库字段中；两者都是仅附加的。原始输出仅接受协议声明的字段，并且除了候选计数限制之外，还具有服务器端字节限制。
- 反向运行、状态事件、Skill 尝试、冲突和未决问题拒绝更新和删除。

## 合并和冲突语义

只有精确稳定的身份才会自动合并。结果保留了所有原始候选人 ID、制作人、陈述和证据。语义相似性不会自动合并到该切片中。

仅当 Claim 类型、主题和 Scope 重叠时才比较机器可读约束。相反的相等、allow/forbid 和不相交集约束会产生 `OPEN` 冲突。听起来矛盾但不相交 Scope 的文本仍然是分开的。任何分数、适配器计数或多数投票都不能覆盖另一个结果。

所有生成的 Claims 都是 `IMPLEMENTATION_BEHAVIOR` 候选者。代码事实可能支持“观察到的实现是这样表现的”；他们没有建立“业务需要这种行为”。

## 故意限制

执行器仅在 API 进程中运行编译的确定性适配器。它不会加载上传的可执行代码并拒绝网络、Shell 和秘密权限。生产外部 Skills 需要单独隔离的 worker/container 边界、签名工作负载身份、网络出口控制、持久异步队列、实时 cancellation/resume、模型网关审核和企业授权。在启用第三方或模型支持的适配器之前，这些控件必须存在。

参考适配器发现以端点为中心的Feature/实现候选者和确定性写入关系。 Specone 兼容适配器还声明通用 `TEST_DESIGN` 功能，并为每个端点发出结构化候选 TestSpec ，包括建议的操作级别、HTTP 步骤、断言、精确 Fact Evidence 以及明确的人工审核要求。它不能批准或执行候选人。更深层次的域规则、状态机和权限语义仍然需要专门的适配器和人工审查。
