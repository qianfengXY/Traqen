## 诊断胶囊

| 栏位 | 记录 |
|---|---|
| 现象 | `2db1f77` 整仓后端 543/544，文档检查失败；web 构建与 80 项测试通过，但类型检查失败、lint 有 3 个警告。 |
| 证据 | 托管任务 `hold-ball-1788774469777-t2syo9`，exit 1 / 335 秒；各命令单独记录退出码，未用 `set -e` 掩盖后续未运行项。 |

| 诊断策略 | 完整枚举文档链接问题；对照主线与本分支差异，追踪回调、状态和 modal 的引用；区分本次回归与未改动的旧模块错误。 |
| 超时策略 | 10 分钟无法确定跨功能归属则向核验过的线程同步证据，不凭猜测修改设置或图谱契约。 |
| 预警策略 | 不提高编译目标、不关 lint、不把存量类型错误当作已通过；不得恢复旧分析入口来消除 unused 警告。 |
| 用户交互 | 保留同一 Workspace 内的来源快照工作台。冻结不启动分析；既有历史读取与显式历史重分析仍保留。没有新的页面布局或导航设计。 |
| 验收 | 当前入口断言 RED → GREEN；source web 行为测试、定向类型检查、零警告 lint 与文档检查。全仓类型检查另行记录，未通过就不宣称完整门禁成功。 |

## 修复与验证

- 文档只修语言导航和诊断记录配对；中文方案继续权威，英文设计仍为历史参考，不恢复双语设计维护。通用模板仅补等价中文副本与互链，不改模板原文、字段或验收语义。
- `0n` 改为 `BigInt(0)`，保持既有编译目标与计数行为。
- 移除旧入口的不可达回调、状态、导入及 modal；不删除服务客户端、F006 设置/Active Profile、历史重分析或其行为测试。
- 更新过时的源码存在性断言，保护 Workspace 绑定的 `SourceTruthWorkbench`，拒绝旧 raw-source 启动接线。该断言先真实失败（1/1），清理后同命令通过（1/1）。
- `node --test web/tests/source-truth-*.test.mjs`：15/15，通过，0 跳过。ES2017 严格目标下，`source-truth/workbench.tsx` 及传递依赖定向 `tsc --noEmit` exit 0。
- `node --test test/bilingual-documentation.test.js`：2/2，通过；`npm --prefix web run lint -- --max-warnings 0` exit 0。原文档检查器未放宽。
- 全仓 tsc 仍有未改动的设置、图谱、旧本地分析及 Worker 类型错误。本次 source 模块错误和旧启动回调类型错误已经消失，但不能据此将全仓 tsc 标为通过。
