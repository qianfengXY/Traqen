## 2. 原样保留与不扩展的边界

- 六组 24 项功能映射、四个页签、五部分交付、四种取证结果继续保留，不新增第七功能组。
- 没有 Fact 的材料仍可发现并受控读取；引用不授予权限，受限原文不预加载，展示副本不改 F001 冻结字节与摘要。
- 声明不等于实现、静态关系不等于执行、测试资产不等于通过、零 Gap 和重放一致不证明完整正确。
- 独立范围全终态才能封存，允许明确 Gap、不允许待处理冒充终态；旧事实不可变，新版本只经明确选择采用。
- 调查授权、预算、停止条件、持久 owner 及受控读取由现有合同约束；本轮不新增权限或降低安全门禁。
- 答卷、会话、贡献、业务影响与发布由上层所属功能负责；不在 F002 新增相关运行时、存储、公共 API 或对外 AI 授权。
- 不改功能基线、Feature Spec、ADR、生命周期或代码；不启动 Task 6 UI，不签 F003 resolver／生产 LOOP、合入或 F002 整体完成。

## 3. 旅程变化与待验收项

原有「技术目录 → 事实 → 原文 → 回调查」保留，新增日常接续：

**回答／会话引用 → 固定材料／事实定位 → 原文、前提与限制核查 → 返回原回答／会话 → 在所属流程继续工作。**

需要补查时，仍另行进入 F003 受授权调查；不能把查看引用或保存发现当成已受理补提。新分析尚未生效时仍读旧依据，新事实集不自动成为回答依据。

正文 §13 的勾选项是未来实现要求，本轮没有执行产品测试、浏览器验收或安全复审。现有 F002 图片原样保留，不证明 V0.6 的新增交互或统一母版；F005 示例通过的检查也不移植为 F002 通过。
