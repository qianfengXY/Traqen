# 与 F005 V1.0 不一样的地方

本表独立于设计正文，便于只看变化。比较对象是[现行 F005 V1.0](../../../design/F005-layout-navigation/README.md)，**不是旧 V2.1 探索稿**。新版是[业务工作台 v0.1 评审稿](README.md)，尚未替换正式规范。

## 1. 实质变化

| 编号 | V1.0 原有设计 | 本版设计建议 | 为什么变／对应旧章节 |
|---|---|---|---|
| D01 | 以来源、事实、业务、影响的清晰阅读为总纲 | 用“理解业务 → 完成当前工作 → 留下依据 → 下次接续”串起页面 | 对齐新愿景；§1–2 |
| D02 | 六个一级入口；概览继续探索、图谱以局部图为主 | 一级导航不变，明确会话归概览、答卷归业务图谱 | F007 MVP 不重排导航；§3–4 |
| D03 | 概览的“继续工作”主要是概念要求 | 具体到问题、材料、参与者、进展、下一步和恢复会话 | 工作必须能接续；§9 |
| D04 | 图谱页默认领域／搜索 → 局部图 → 检查器 | 业务详情默认建议七问答卷；关系图成为同业务另一视图 | 接手者先读懂业务，再沿关系查证；§9–10 |
| D05 | 已有对象／关系依据，缺统一答案条目阅读模型 | 每条回答带范围、版本、来源、依据、状态与评估时点；确认来源条件展示 | 答卷是派生投影，不能另造权威；§10、13 |
| D06 | 意图、实现、测试等材料分布在对象及检查器 | 将同一回答的意图与实现观察并列，保留矛盾与未知原因 | 避免摘要自动抹平分歧；§9–11 |
| D07 | 未专门规定可先于业务存在的工作会话 | 会话可以没有业务归属；后来关联业务与冻结材料 | 不知道归属也能开始调查；§3、9、11 |
| D08 | 人工决定／调查入口存在，缺会话内统一回写分路 | 调查发现、正式决定、新材料、执行结果四种去向及不同成立条件 | 回写不应直接改答案或绕过来源；§8、10–11、13 |
| D09 | 状态独立，主要描述对象和运行 | 答案明确五维；列表强调当前理由，详情展开；不生成总分 | 说得清不等于系统正常；§8、10–11 |
| D10 | 影响页展示比较两端、路径与建议 | 增加受影响答案、影响理由、复核入口，以及当前答卷／新分析分区 | 变化后知道具体重查哪里；§9、11 |
| D11 | 已有过期／失效与旧来源保留 | 明确新分析未生效仍读旧头、决定到期不依赖代码变化 | 让状态变化有清晰的阅读后果；§11、14 |
| D12 | 返回保留对象、查询、位置、版本 | 扩展为业务＋会话＋回答位置＋各自版本的跨页接续 | 查原文不丢当前工作；§3–4、13 |
| D13 | 设置以 F006 模型、Skill、团队能力为主 | 增加入站 AI 只读范围的可理解呈现，与出站模型授权区分 | 共享知识不等于共享全部原文；§2、9、13 |
| D14 | 基础控件、图谱、EvidenceReference 等 | 新增答案、未知原因、版本摘要、会话时间线、分类回写、影响条目组合组件 | 复用底层控件，增加业务工作表达；§13 |
| D15 | 验收聚焦导航、来源恢复、图谱阅读、配置、主题与缩放 | 增加接手、回写复用、变化举手、发布回路、决定到期、AI 读取与恢复旅程 | 从页面可用扩展到工作能够完成；§14 |
| D16 | 历史组件／图谱截图；无新统一母版成果 | 同一示例四个主场景，加深色和 1.6 倍对照；附可操作 HTML | 用完整场景审查新方向；§15–16 |

## 2. 明确保留的要求

| 保留项 | 本版边界 |
|---|---|
| 一套桌面设计 | 1440×900 母版；14 寸／27 寸仅整体缩放；不增加大屏专属内容 |
| 两种默认主题 | 瓷白 light、石墨 dark；完整语义 token，可扩展 |
| 六个主导航与路由 | overview / sources / evidence / graph / impact / settings |
| 基础视觉规范 | 224 侧栏、32 边距、302 检查器、克制层次、系统字体及现有圆角与间距 |
| 来源与版本语义 | 来源／事实／图谱分开；冻结不自动启动分析；未知不借用别的身份 |
| 分流与人工权威 | 充分支持自动收录分析态，真正歧义才交人；不恢复逐项人工批准 |
| 测试与证据 | 测试资产不等于执行通过，决定不抹掉反证 |
| F004 首期边界 | 建议性影响，不自动拦合并或部署 |
| 可访问性与恢复 | 继承 V1.0 要求；样稿局部验证不能替代生产完整验收 |
| 窄屏范围 | 手机、平板与移动专用交互暂不设计 |

## 3. 本版没有提前决定的内容

- F007 的实际单块试点业务和试点关系类型清单。
- 新增会话、贡献和答卷投影的物理数据结构、API 与实现负责人。
- F007 §9 的执行证据独立更新和页面降级条件；本稿保留建议场景。
- 二期导航重排、AI 回写与业务数据对象；三期正向登记和通用外部接入；四期平台集成等。
- 正式规范采纳、产品部署、真实业务权限、发布门禁或恢复验收。

## 4. 最直观的体验差异

同样是“取消订单”：V1.0 强调找到节点、看关系和依据；本版首先让接手者读到当前规则和未知，再按需要进入关系／原文，并把调查理由保存在可继续的工作会话中。关系探索保留，阅读与工作接续得到独立设计。

建议评审时先走一遍：**概览继续核对 → 七问规则 → 固定原文 → 回到原回答 → 会话记录说明 → 新材料影响复核**。再核对同页面两主题、两显示倍率是否保留相同信息。
