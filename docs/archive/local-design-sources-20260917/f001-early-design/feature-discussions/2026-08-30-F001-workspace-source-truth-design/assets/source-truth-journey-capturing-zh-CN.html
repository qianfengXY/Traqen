下一步：⑤ 核对结果

所有文件写入管理存储后，系统会冻结最终 manifest 并与来源声明对账。核对通过后才能 Seal；核对失败会进入可重试失败或阻断状态，不会签发 Receipt。

流程规则

① Git 与目录是独立来源组件，不是互斥三选一；② 目录上传区分全量与增量，增量以上一版 manifest 为基线；③ 只有 Seal 后的 Receipt 才能进入 F002；④ 阻断状态无接受/绕过按钮。
